## Загальна структура MainWindow

Вікно поділено на 4 горизонтальні зони (зверху вниз):

```
┌──────────────────────────────────────────────┐
│  Menu bar (Alt — вхід)                       │
│  Файл | Потік | Довідка                       │
├──────────────────────────────────────────────┤
│  TabControl (Ctrl+1..5)                      │
│  [Потоки] [Пісні] [Wishlist] [Розклад] [Лог] │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │        Вміст обраної вкладки             │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│  PlayerPanel (завжди видима)                 │
│  ▶/⏸  ⏹  [Назва треку]  00:00  ──●── 🔊    │
├──────────────────────────────────────────────┤
│  StatusBar                                   │
│  Записів: 3 | 45 ГБ вільно | Профіль: Default│
└──────────────────────────────────────────────┘
```

**Tab Order головного вікна:** Menu (0) → TabControl (1) → PlayerPanel (2) → StatusBar (3).
Цикл: `KeyboardNavigation.TabNavigation="Cycle"`.

**Тулбар:** відсутній у v1; може з'явитися в наступних версіях.

## Menu bar

Мінімальне меню. Точка входу для скрінрідер-користувачів (Alt відкриває).

### Обґрунтування

- Перше, що робить незрячий користувач у новій програмі — натискає Alt.
- `MenuAutomationPeer` — нативний WPF, нульовий кастомний код.
- Меню приховує рідковживані команди (імпорт/експорт, про програму).

### Структура

```
Файл (Alt+F)
  ├─ Профіль ►                          → підменю вибору профілю
  │    ├─ ● Default                       (RadioButton-стиль, поточний позначено)
  │    ├─ ○ Музика
  │    └─ ○ Новини
  ├─ ─────────────
  ├─ Налаштування…          (Ctrl+,)
  ├─ Імпорт профілю…
  ├─ Експорт профілю…
  └─ Вихід                   (Alt+F4)

Потік (Alt+P)
  ├─ Додати потік…           (Ctrl+N)   → AddStreamDialog
  ├─ Знайти станції…         (Ctrl+F)   → StreamBrowserDialog
  ├─ Почати запис             (F5)
  └─ Зупинити запис           (F6)

Довідка (Alt+D)
  ├─ Гарячі клавіші…
  └─ Про RadioReel…
```

Кожен пункт має AccessKey (підкреслена літера) для навігації без миші.

### Швидке перемикання профілю

Вибрано **Варіант D** (підменю + гарячі клавіші):

- **Ctrl+Alt+↑** — наступний профіль (циклічно)
- **Ctrl+Alt+↓** — попередній профіль (циклічно)
- При перемиканні — NVDA Assertive: "Профіль змінено: {назва}"
- Меню «Файл → Профіль» — для discoverability та повного списку
- StatusBar показує поточний профіль (read-only TextBlock)

**Обґрунтування:** нульовий вплив на Tab flow (нема зайвих Tab-стопів); одна комбінація клавіш — найшвидше; меню забезпечує discoverability.

## Вкладки (TabControl)

5 вкладок, перемикання: Ctrl+1 … Ctrl+5.
`TabControlAutomationPeer` повідомляє позицію ("вкладка 2 з 5") та назву.

### Обґрунтування вибору TabControl (замість альтернатив)

| Підхід | Плюси | Мінуси для скрінрідера |
|--------|-------|----------------------|
| **TabControl** | Нативний AutomationPeer; Ctrl+1..5; NVDA каже "вкладка 1 з 5, Потоки" | — |
| TreeView-сайдбар | Вкладеність | Не оголошує контент-область; складніша навігація |
| ComboBox-перемикач | Компактно | Менш інтуїтивно; не прив'язує до контенту |
| Expander-секції | Все на одній сторінці | Надмірна прокрутка; втрата контексту |
| Окремі вікна | Простота | Втрата контексту; PlayerPanel не видима |

### Вкладка 1 — «Потоки» (Ctrl+1)

Основний список радіостанцій. `ListView` з `GridView`.

**Tab Order:**

1. **Панель дій:**
   - Button «Почати запис» (F5)
   - Button «Зупинити запис» (F6)
   - Button «Відтворити»
2. **TextBox «Фільтр»** — фільтрація списку за назвою (AutomationProperties.Name="Фільтр потоків")
3. **ListView «Список потоків»** — AutomationProperties.Name="Список потоків"

**Колонки ListView:**

| Колонка | AutomationProperties.Name | Приклад |
|---------|--------------------------|---------|
| Назва | "Назва станції" | Radio Paradise |
| Статус | "Статус" | Записується / Зупинено / Помилка |
| Поточний трек | "Поточний трек" | Pink Floyd — Comfortably Numb |
| Бітрейт | "Бітрейт" | 128 kbps |
| Формат | "Формат" | MP3 |

- **Статус:** LiveSetting="Polite" — при зміні статусу NVDA оголошує.
- **Поточний трек:** LiveSetting="Polite" — при зміні треку NVDA оголошує.

**Контекстне меню (Shift+F10):**
- Почати запис (F5)
- Зупинити запис (F6)
- Відтворити

- Редагувати потік…

- Копіювати URL
- Показати в браузері станцій

**Навігація:** ↑↓ між потоками; Home/End — перший/останній; Enter — дія за налаштуванням.

## Діалогові вікна

Всі діалоги — модальні Window. Фокус при відкритті → перший елемент. Escape закриває.

### 1. AddStreamDialog

Додавання нової станції.

**Поля (Tab Order):**
1. TextBox «URL потоку» — обов'язкове
2. TextBox «Назва станції» — опціонально
3. TextBox «Макс. спроб перепідключення» — (0 = нескінченно)
4. TextBox «Інтервал перепідключення (сек)» — за замовчуванням 5
5. Button «Перевірити підключення»
6. Button «Додати» (IsDefault)
7. Button «Скасувати» (IsCancel)

### 2. StreamSettingsDialog

Налаштування обраного потоку.

**Поля (Tab Order):**
1. TextBox «Папка збереження» + Button «Огляд…»
2. TextBox «Шаблон імені файлу»
3. TextBox «Шаблон для неповних треків»
4. TextBox «Шаблон для файлу потоку»
5. TextBox «Мін. тривалість треку (сек)»
6. Група «Локальний Ignorelist» — ListView + Додати/Видалити
7. Button «Зберегти» / Button «Скасувати»

### 3. SettingsDialog

Загальні налаштування. Розділено внутрішнім TabControl або секціями:

- **Загальне:** мова, тема, згортання в трей, назва треку у заголовку, автозапуск (з попередженням), поріг диску
- **Запис:** дія при подвійному кліку, збереження потокового файлу, видалення після зупинки, тільки повні пісні
- **Гарячі клавіші:** список призначених клавіш зі зміною
- **Профілі:** список + Створити/Копіювати/Видалити/Імпорт/Експорт
- **Постобробка:** конвертація, цільовий формат, зовнішній скрипт, **ListView «Черга постобробки»** (колонки: Файл, Статус, Дія; контекстне меню: Видалити з черги)
- **Мережа:** ліміт пропускної здатності, проксі

### 4. StreamBrowserDialog

Пошук станцій через Radio Browser API.

**Елементи (Tab Order):**
1. TextBox «Пошук за назвою» — AutomationProperties.Name="Назва станції"
2. TextBox «Жанр/тег» — AutomationProperties.Name="Жанр або тег" (PRD §4.5.1)
3. ComboBox «Формат» — MP3 / AAC / Всі
4. TextBox «Мін. бітрейт»
5. Button «Шукати»
6. ListView «Результати пошуку» — Назва, Країна, Жанр, Бітрейт, Формат, Метадані
7. Button «Додати обрані до списку потоків»
8. Button «Закрити»

### 5. TagEditorDialog

Редагування ID3/AAC тегів збереженого файлу (PRD §4.7).

**Поля (Tab Order):**
1. TextBox «Артист» — AutomationProperties.Name="Артист"
2. TextBox «Назва» — AutomationProperties.Name="Назва треку"
3. TextBox «Альбом» — AutomationProperties.Name="Альбом"
4. TextBox «Жанр» — AutomationProperties.Name="Жанр"
5. TextBox «Номер треку» — AutomationProperties.Name="Номер треку"
6. CheckBox «Автокорекція регістру» — AutomationProperties.Name="Автоматична корекція регістру (Artist - Title)"
7. TextBlock «Файл» — шлях до файлу (read-only)
8. Button «Зберегти» (IsDefault)
9. Button «Скасувати» (IsCancel)

### 6. ScheduledRecordingDialog

Додавання/редагування запланованого запису.

**Поля (Tab Order):**
1. ComboBox «Потік»
2. TextBox «Назва» (опціонально)
3. ComboBox «День тижня»
4. TextBox «Час початку» (HH:MM)
5. TextBox «Тривалість (хв)»
6. ComboBox «Тип» — Одноразовий / Повторюваний
7. CheckBox «Увімкнено»
8. Button «Зберегти» (IsDefault)
9. Button «Скасувати» (IsCancel)
